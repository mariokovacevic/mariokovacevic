## 👨‍💻 About me

Senior iOS developer from Banja Luka, writing software since 2012 and shipping native Apple apps since 2014, from banking and payments to airline and enterprise intercom apps. Most of my work today sits where iOS meets real-time communication: SIP/VoIP, CallKit, PushKit, ICE/STUN/TURN, and the debugging rabbit holes in between. On the server side I write Swift too, with Vapor, Fluent and Postgres.
